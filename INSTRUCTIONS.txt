================================================================================
  M-LIS — LABORATORY INFORMATION SYSTEM
================================================================================

This package contains the complete offline M-LIS system.
No internet connection is required.

--------------------------------------------------------------------------------
1. FIRST TIME SETUP (DO THIS ONCE ON A NEW PC)
--------------------------------------------------------------------------------
Step 1: Install Python (if not already installed)
        - Run Python installer (Python 3.11 or higher).
        - IMPORTANT: Make sure to check the box: "Add Python to PATH"

Step 2: Double-click "setup.bat"
        - This will automatically install all offline packages, set up the
          local database, and create a shortcut on your Desktop.
        - If any error occurs, check "setup_debug.log" in this folder.

--------------------------------------------------------------------------------
2. DAILY OPERATION (STARTING THE SYSTEM)
--------------------------------------------------------------------------------
- Double-click the "M-LIS" shortcut on your Desktop
  OR double-click "run.bat" in this folder.
- Your web browser will open automatically at: http://127.0.0.1:8756/
- Keep the server window open while using the system.

--------------------------------------------------------------------------------
3. USER ACCOUNTS & FIRST-RUN SETUP
--------------------------------------------------------------------------------
- No default accounts or passwords exist in the system for security.
- On your first launch, navigate to http://127.0.0.1:8756/ and click "Register".
- Fill in your staff details (Full Name, Username, Cadre, Password).
- The FIRST user account created automatically becomes the active Super Administrator.
- Subsequent staff registrations will be placed in pending status until approved
  by the Administrator from the User Management panel.

--------------------------------------------------------------------------------
4. HOW TO UPDATE / DEPLOY MODIFIED FILES
--------------------------------------------------------------------------------
- To deploy an updated file (such as a parser or UI fix), simply copy and
  paste the modified file into its corresponding folder (e.g. backend/ or frontend/).
- Restart the system by running "run.bat".
- Your patient and test database in the "data/" folder will NOT be affected.

--------------------------------------------------------------------------------
5. TROUBLESHOOTING & SELF-HEALING
--------------------------------------------------------------------------------
- If setup.bat displays an error about Python:
  Select option 1 to specify python.exe path, or edit "python_env.bat" directly.
- If dependencies fail or Python version differs:
  The setup will run "Pre-Installation Check".
  If connected to internet, select the online install option to fetch matching packages.
  If offline, ensure target PC has Python 3.11 or 3.14 (64-bit).
- If port 8756 is occupied:
  "run.bat" will automatically detect and clear any stuck ghost process on launch.
- Review logs:
  Open "setup_debug.log" in Notepad.
================================================================================
